# Immagine principale della homepage

File atteso: `hero-flora-italiana.webp`, proporzione **13:10 orizzontale**, almeno 1600 × 1230 px.

Per attivarla: copia il file qui e in `js/data/taxonomy.js` cambia `FLORA.meta.hero.status` da `"pending"` a `"ready"`.
Se l'immagine è generata con AI lascia `ai: true`: il sito mostrerà l'etichetta "illustrativa, non documentale".
Finché il file non c'è, la homepage mostra una tavola illustrata disegnata in codice.
